# Índice de Agentes de IA

Esta pasta contém agentes especialistas para cada função essencial no desenvolvimento do AssembleiaApp. Use cada agente conforme a necessidade descrita abaixo.

## Agentes Disponíveis

- **backend-django.md**: Backend Django Agent
  - Especialista em backend Django e Python. Use para lógica de negócio, APIs, integrações e modelagem.
- **frontend-django-template.md**: Frontend Django Template Agent
  - Especialista em Django Template Language e TailwindCSS. Use para templates, componentes visuais e design system.
- **qa-tester.md**: QA/Test Agent
  - Especialista em testes end-to-end e validação de interface. Use para garantir funcionamento e qualidade visual.

Cada agente utiliza os MCP servers adequados para garantir código e validações alinhados às melhores práticas da stack do projeto.
