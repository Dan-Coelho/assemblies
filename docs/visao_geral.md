# Visão Geral

O AssembleiaApp é uma plataforma web SaaS para gestão de assembleias de condomínios, sindicatos e associações. Centraliza o ciclo de vida das assembleias: convocação, credenciamento, votação (presencial, remota ou híbrida) e geração de atas digitais.

Problema resolvido: elimina processos manuais, reduz riscos jurídicos e aumenta a rastreabilidade.
